Baseline / Candidate

Baseline/Candidate относятся к конкретному сравнению, а не к artifact навсегда. План можно сравнить без выполнения запроса. Проверка данных и EXPLAIN ANALYZE реально выполняют SELECT и создают нагрузку на выбранное подключение.

Сравнить SQL на PostgreSQL

Выполнение запросов. `Сравнить данные` и `EXPLAIN ANALYZE` реально выполняют оба SELECT. Парсер запрещает writable statements, а PostgreSQL session работает `default_transaction_read_only=on`, но SELECT может вызывать пользовательские функции.
`EXPLAIN` не выполняет SELECT. `EXCEPT ALL` сохраняет multiplicity и ловит различия в дублях, если обе стороны имеют совместимый row shape.
