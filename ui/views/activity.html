Текущие backend processes

Cancel отправляет SIGINT текущему query и сохраняет соединение. Terminate отправляет SIGTERM backend и обрывает сессию; открытая транзакция будет rollback. pgXray разрешает эти действия только для client backend. PostgreSQL дополнительно проверяет права роли.

    Настройки PostgreSQL

    pgXray сохраняет снимки pg_settings и сравнивает их во времени. Автосрез выполняется раз в 24 часа, пока pgXray запущен; после следующего входа пропущенный срез догоняется. Точное время внешнего изменения PostgreSQL неизвестно: pgXray показывает интервал между последним старым и первым новым snapshot.
