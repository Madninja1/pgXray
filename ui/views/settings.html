Пути хранения

Export directory используется для ручного экспорта artifacts. Workspace root содержит cases, artifacts и privacy mappings. Application log directory содержит JSONL-журнал работы pgXray. Локальные SQLite базы pgXray остаются в системном каталоге приложения.

Export directory

По умолчанию pgXray использует ~/Downloads/pgxray. Каталог создаётся при необходимости и должен быть доступен для записи.

Workspace root

При изменении pgXray копирует существующий workspace в новый пустой каталог, переключает приложение на новый путь и затем удаляет старый каталог. Во время переноса все psql-сессии должны быть закрыты.

Parent directory должен уже существовать. Сам target может отсутствовать или быть пустым. Symlink внутри переносимого workspace не поддерживаются.

Application log directory

Здесь хранятся JSONL-файлы журнала приложения. При смене пути pgXray переносит существующие log-файлы, переключает logger и затем удаляет старый каталог, если он пуст.

Parent directory должен существовать. Новый target может отсутствовать или быть пустым каталогом. Symlink не поддерживается. Retention и size limit после переноса продолжают действовать.

История диагностики

Retention применяется к XID, pg_stat_statements и Autovacuum snapshots. Очистка истории не удаляет profile подключения, cases или artifacts.

Журнал приложения

Журнал сохраняет lifecycle приложения, значимые UI/backend операции, длительность и внутренние фазы PostgreSQL client. pgXray намеренно не записывает пароли, SQL bodies, результаты запросов и terminal keystrokes. Текст ошибки сохраняется для диагностики и может содержать детали, возвращённые PostgreSQL или ОС.

Хранение

Файлы ротируются примерно по 16 MiB. Очистка применяется одновременно по возрасту и по общему размеру: срабатывает более строгое ограничение.
